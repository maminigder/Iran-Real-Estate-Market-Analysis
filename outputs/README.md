# Outputs

This folder is reserved for reproducible analysis outputs generated by `src/market_analysis.py`.

Expected files include:

- `market_summary.json`
- `city_summary.csv`
- `amenity_summary.csv`
- `top_cities_by_listing_count.png`
- `median_price_per_sqm_by_city.png`

Generated files are ignored by Git during early development so that only validated portfolio-ready outputs are committed later.
